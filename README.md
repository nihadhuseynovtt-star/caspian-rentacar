# Caspian Rent a Car – Next.js Şablon

Modern avtomobil kirayə platforması (Next.js 14+, App Router ilə qurulub).

### Özəlliklər
- Responsive ana səhifə (Bakı fonlu)
- Admin paneli (maşın əlavə et / sil)
- Şəkillər URL vasitəsilə əlavə olunur
- Məlumatlar localStorage-da saxlanılır
- TypeScript + Tailwind CSS

### Quraşdırma
```bash
# Layihəni klonla
git clone https://github.com/nihadhuseynovtt-star/caspian-rentacar.git

cd caspian-rentacar

# Paketləri quraşdır
npm install

# Lokal serveri işə sal
npm run dev
